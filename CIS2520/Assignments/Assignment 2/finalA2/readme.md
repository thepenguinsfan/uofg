## Assignment Overview
What is the assignment about?  
Explain the purpose of the program and what it accomplishes.

The purpose of question 1 of the assignment is to create 3 lists of cars. The lists
are: cars available to rent, rented cars, and cars in repair. The contents of each list
are stored in a text file that the program reads upon runtime. On exit, the program writes new data to 
each file, ensuring the lists stay updated and data is saved after the program exits. The user can perform 6 
operations to these lists:
  1. Add a new car to the available-for-rent list
  2. Add a returned car to the available-for-rent list
  3. Add a returned car to the repair list
  4. Transfer a car from the repair list to the available-for-rent list
  5. Rent the first available car
  6. Print all the lists
When each option is selected, the program will call the necessary functions in order to complete these operations.

The purpose of question 2 is to implement a linked list implementation of stacks in order to compute expressions in 
Reverse Polish Notation(RPN). The program takes the expression from the command line and uses the necessary push and pop
operations in order to compute the correct result.

## Assignment Overview
What is the assignment about?  
Explain the purpose of the program and what it accomplishes.

The purpose of this assignment is to read an adjacency matrix from a file as input, and create a graph based off the adjacency matrix. Then, a menu will display the following actions:
1.	Display Adjacency List
2.	Perform Breadth-First Search (BFS)
3.	Perform Depth-First Search (DFS)
4.	Find Shortest Path using Dijkstra's Algorithm
5.	Exit

The first operation will display the adjacency list representation of the graph.
The second operation will perform a Breadth-First Search starting from vertex 1, printing the vertices in the order they were visited.
The third operation will perform a Depth-First Search traversal starting from vertex 1, printing teh vertices in the order they are visited.
The fourth option will compute and print the shortest paths from vertex 1 from vertex 1 to all other vertices using Dijkstra's algorithm.
Quitting the program will free all dynamically allocated memory and exit the program.
